# SillyTavern 消息提示音替换（酒馆助手脚本）

一个极简的 **SillyTavern（酒馆）** 消息提示音替换脚本，支持远程自动更新、多款经典游戏提示音切换、音量调节与自定义音频。

> **说明**：本脚本只负责**替换提示音音源**与**调节音量**，「消息声音」和「仅背景声音」的开关仍完全沿用酒馆自带设置。

---

## 功能特点

- **原生融入**：UI 直接嵌入在酒馆「用户设置 → 杂项」的 **消息声音 / 仅背景声音** 开关紧下方，不占聊天空间，无悬浮球。
- **内置 34 款精选完整短音效**（按需懒加载，不拖慢酒馆启动速度）：
  - **塞尔达传说**：解谜成功、发现克洛格 (Yahaha!)、获得道具、拾取卢比
  - **星露谷物语**：钓鱼上钩
  - **Minecraft**：经验球、升级提示
  - **宝可梦**：精灵中心回复、升级音效
  - **经典游戏**：超级马里奥（吃金币 / 1UP）、索尼克金币环、PlayStation 奖杯、Switch 咔哒、动物森友会打招呼、空洞骑士小幼虫、合金装备惊叹号
  - **开源轻提示 (CC0 / Kenney)**：13 款清脆双音、玻璃叮咚、水滴气泡、拨弦、柔和木琴、上扬与提问音
  - **日常提示音**：Discord 消息提示、iPhone 短信叮、清脆小铃铛、清脆泡泡啵
- **0% – 300% 音量增益调节**：基于 Web Audio API（`GainNode` + 防破音限幅器），支持超过 100% 的响度放大，同时兼容手机/iOS 音量滑块。
- **自定义音频**：支持粘贴外部音频直链，或直接上传本地短音频（≤ 2MB）。
- **远程推送更新**：采用「加载器 + 远程主脚本 + 远程音效清单」架构，仓库推送更新后，刷新酒馆即可自动同步。

---

## 安装方法（仅需一次）

1. 在 SillyTavern 中打开 **扩展 → 酒馆助手（JS-Slash-Runner）→ 脚本库**。
2. 新建一个 **全局脚本**（名称随意，如 `消息提示音替换`）。
3. 复制仓库中的 [`loader.js`](./loader.js) 全部内容粘贴进去，保存并启用。
4. 刷新酒馆，打开顶部 **用户设置 → 杂项**，在「仅背景声音」下方即可看到提示音选择和音量滑块。

---

## 远程推送更新 & 新增预设音效

- **新增预设音效**（无需改代码）：
  1. 将新的 `.mp3` 音频文件放入 `sounds/` 目录。
  2. 在 `sounds.json` 中追加一条记录：
     ```json
     {
       "id": "unique-id",
       "name": "显示名称",
       "group": "分组名称",
       "file": "sounds/你的文件.mp3"
     }
     ```
  3. 提交并推送到 `main` 分支，所有用户刷新酒馆即自动拉取新音效。
- **更新脚本功能**：直接修改 `sound-replacer.js` 并推送到 `main` 分支即可。
